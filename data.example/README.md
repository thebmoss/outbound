# Synthetic fixtures

Every name, company, number and date in this directory is invented. These files
exist so the repository is runnable, testable and demonstrable without the
operator's real data, which lives in the ignored `data/` directory.

The shapes here mirror `docs/design/domain-model-proposal.md`. When that model
changes in Mob Elaboration, these change with it, and the tests that read them
are how we find out whether the change broke anything.
